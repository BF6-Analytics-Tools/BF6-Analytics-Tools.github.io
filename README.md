## 📌 About the Project

A collection of advanced performance analysis and telemetry tools for Battlefield 6. Each tool provides real-time tracking, visual overlays, and gameplay improvement features.

---

## 🔧 Available Tools

- **FECURITY** — Performance analyzer with silent aim overlay, player and vehicle tracking, and large-scale combat visualization.
- **FROST** — External analyzer with adjustable aimbot, trigger overlay, and smart objective awareness for massive battles.
- **ANCIENT** — Humanized aimbot analyzer with ESP backlight, large-scale combat optimization, and ban protection insights.
